## Description (from catalog)
Students use industry-standard tools and develop customized solutions for binary/code analysis. Using real-world vulnerability classes, the course examines how attackers identify flaws in modern software and exploit them while bypassing modern OS protection mechanisms. Students also patch issues and extend protection mechanisms. Methods: static analysis, dynamic analysis, fault injection, fuzzing.

Prerequisite: familiarity with computer architecture concepts.
