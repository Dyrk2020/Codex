## 课程简介

- **cs61a-2023** — 全量课程资料及答案(Projects / Labs / HW / Discussion / Exams)、自学笔记与官方 cs61a.org 站点存档。
- **cs61b-2024** — 官方 skeleton / library / 课堂示例代码,以及 sp24.datastructur.es 完整站点镜像。
- **cs329a-stanford** — 完整 20 讲课程日程,附全部论文链接与评分政策。
- **cmu-agents-11768** — 官网为客户端渲染 SPA,以下为 headless Chromium 渲染提取的日程 / 大纲 / 作业 / 教师信息,含第一讲课件与原始页面备份。
- **jhu-695744-reverse-engineering** — 课程目录页内容,含教材与教学大纲链接。
- **hss-purdue** — purs3lab/hss 完整 Jekyll 站点源码(lectures / assignments / schedule / materials)。
- **cs598lmz-uiuc** — 5 份教师讲义 PDF 与课程页存档;其余课时为论文研讨,无教师课件。
- **software-agents-uiuc** — 仅课程大纲 README 副本;正式资料发布在 Campuswire / Canvas,无公开文件。
