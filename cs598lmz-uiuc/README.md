## Syllabus modules
- Module I: Background and Basics (program analysis, testing, debugging, LLM basics)
- Module II: Code LLMs (encoder-only / encoder-decoder / decoder-only / instruction tuning)
- Module III: Code LLMs for Software QA (fuzzing, unit testing, program repair, debugging, program analysis, verification)
- Module IV: Software QA for Code LLMs (benchmarking, correctness, code security, model security/jailbreaks, system reliability)
